# 私人保险箱

一个纯静态的加密保险箱，可以托管在 GitHub Pages 上。

- 加密方式：主密码先用 PBKDF2-SHA256（600,000 次迭代）派生出密钥，再用 AES-256-GCM 加密，全部在浏览器里完成（WebCrypto）。
- 仓库里只保存 `vault.json`，里面全是密文。主密码和明文从来不会离开你的浏览器。
- 本设备上的修改会以密文形式存在浏览器的 IndexedDB 里。要同步到其他设备，点 **导出加密文件**，然后用下载的文件替换仓库里的 `vault.json`，提交并推送。
- 无操作 5 分钟后自动锁定。复制的密码 30 秒后会从剪贴板清除。

**请使用强主密码**（建议是一个长句子，16 位以上）。`vault.json` 可能被别人看到，它的安全完全取决于主密码的强度。主密码忘了就无法找回。
