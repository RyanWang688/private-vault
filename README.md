# 密匣

<img src="logo.svg" width="72" alt="密匣 logo">

Logo 的核心是“方匣上的一道光缝，缝里悬着一个节点”：匣代表加密收藏，节点呼应图谱。设计稿在 `brand/`，单色版是 `logo-mono.svg`。

一个纯静态的加密保险箱，托管在 GitHub Pages 上。用卡片管理账号密码、证件、银行卡、笔记和文件，还有一个图谱视图，能看到卡片之间的关系。

## 安全设计
- **双重密钥**：主密码先经 PBKDF2-SHA256（1,000,000 次迭代）处理，再和一把 160 位的随机**秘密钥匙**一起经 HKDF 派生，最后用 AES-256-GCM 加密。
- 没有秘密钥匙的话，要破解至少得猜 2¹⁶⁰ 种组合，暴力破解或爬虫都无从下手。秘密钥匙只保存在你的设备上和你自己保管的应急包里，**不要上传到 GitHub**。
- 文件头和每个文件的编号都作为附加认证数据（AAD）参与加密，被篡改后无法解密。
- 严格的 CSP：不加载任何外部脚本，页面设置了 noindex，并禁止被嵌入 iframe。

## 存储结构
| 路径 | 内容 |
|---|---|
| `vault.json` | 加密后的文字信息：卡片、字段、标签、缩略图，以及文件的“数据密钥” |
| `blobs/<随机编号>.bin` | 每个文件单独用数据密钥加密（AES-256-GCM），文件名是随机的 |
| `lib/pdfjs/` | Mozilla pdf.js 3.11.174（Apache-2.0），自托管，用于 PDF 预览和转图片 |

- 换设备时只会先下载 `vault.json`；点开某个文件时才下载那一个 `.bin`，下载后缓存在本地（仍是密文）。
- 修改主密码只需重新加密 `vault.json`，不用重新加密文件。

## 同步
1. 在网站上点 **未同步**，下载 `vault-sync-日期.zip`（文字信息 + 新增的文件）。
2. 运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File D:\workshop\private-vault\tools\apply-sync.ps1 "<同步包路径>"
   ```
   脚本会检查同步包里只有密文，更新 `vault.json`，加入新文件，删除已经不用的文件，然后提交并推送到 GitHub。

“设置 → 导出完整备份”会打包全部文件，可以离线保存，或在新设备上直接“导入”。
