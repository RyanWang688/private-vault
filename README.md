# 私人保险箱

一个纯静态的加密保险箱，托管在 GitHub Pages 上。用卡片管理账号密码、证件、银行卡、笔记和文件，还有一个图谱视图，能看到卡片之间的关系。

## 安全设计
- **双重密钥**：主密码先经 PBKDF2-SHA256（1,000,000 次迭代）处理，再和一把 160 位的随机**秘密钥匙**一起经 HKDF 派生，最后用 AES-256-GCM 加密。
- 仓库里的 `vault.json` 只有密文。不知道秘密钥匙的话，要破解至少得猜 2¹⁶⁰ 种组合，暴力破解或爬虫都无从下手。
- 秘密钥匙只保存在你的设备上和你自己保管的应急包里，**不要上传到 GitHub**。
- 文件头作为附加认证数据（AAD）参与加密，被篡改后无法解密。
- 输错密码会逐步延长等待时间；一段时间不操作或离开页面会自动锁定；复制的密码 30 秒后从剪贴板清除。
- 严格的 CSP：不加载任何外部脚本，除了读取同站点的 `vault.json` 外不发送任何网络请求；页面设置了 noindex，并禁止被嵌入 iframe。

## 同步
修改会以密文形式存在本设备的浏览器里。点 **未同步 / 导出 vault.json**，然后用下载的文件替换仓库里的同名文件，提交即可。

## 文件
- 把文件拖进窗口即可加密保存，单个文件最大 25MB，总量约 70MB（受 GitHub 单文件大小限制）。
- 把文件卡片或详情里的文件条拖到桌面、文件夹（Chrome / Edge），或其他网站的上传区，即可直接拖出；图片还可以一键复制后粘贴。
